# DeepSeek V4.1-Flash

PolyStrata no longer runs DeepSeek V4.1-Flash. Version 0.2.13 was the last one that set it up and started it on a Mac.
Model files you already downloaded stay where they are. When you try to start one, PolyStrata names the folder and its size, so you can delete it if you no longer need it.
To run a model now, run setup (`START-HERE.bat --setup` or `./setup.sh --setup`) and choose another one: the README lists
them. DeepSeek V4 Flash on PolyStrata's own engine is a different model ([deepseek.md](models/deepseek.md)).
